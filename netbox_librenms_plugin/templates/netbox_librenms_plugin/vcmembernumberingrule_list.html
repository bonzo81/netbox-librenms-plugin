VC Member Numbering Rules

Decide the NetBox virtual chassis position of each stack member that an import creates. Number from 1 adds 1 to every member number when LibreNMS numbers the stack from 0. Reported numbers keeps the numbers that LibreNMS reports. Without a rule, the import keeps the reported numbers.

The rule of the imported device type applies: a rule with a manufacturer and a device type pattern first, then a pattern only, then a manufacturer only, then a rule without either. In one of these groups, the lowest ID wins. A rule change does not renumber existing members.
