IP Mapping

An IP mapping keeps the LibreNMS addresses in a prefix out of IP sync. The IP Addresses sync tab shows such an address as Ignored and does not create or update it in NetBox. It never deletes an address that NetBox already has.

Example: Ignore prefix "fe80::/10" to keep IPv6 link-local addresses out of NetBox. Set a VRF to apply the mapping only to addresses synced into that VRF.
