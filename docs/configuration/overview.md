# Configuration

Use these guides to configure how the plugin connects to LibreNMS and handles imported or synchronized data.

- [Plugin Import Settings](import_settings.md) controls device naming and location parsing during import.
- [Multi-Server Setup](multi_server_configuration.md) explains how to configure and select LibreNMS servers.
- [Mappings](mappings.md) translates LibreNMS values into NetBox values.
- [Rules & Patterns](rules_and_patterns.md) adjusts or filters LibreNMS data.
- [Permissions & Access](permissions.md) explains the permissions required to use the plugin.
- [Custom Field Setup](custom_field.md) explains how the plugin identifies matching objects.
